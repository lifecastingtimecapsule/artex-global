# 日本語デスクトップ版の追加機能

日本語UI、ファイル・フォルダーの選択とドラッグ入力、公開GitHubソースの取り込み、Web URLの対象登録、回答待ちと無進展時の停止を追加。

## テンプレート

`templates.json` は13用途の説明・目標の原本。ARTEXのテンプレート管理画面で各項目を保存して利用する。JSONの自動インポート機能を追加したものではない。

未指定時は今回渡されたファイル全体を対象に、全ファイルの台帳を作り、必要・不要とその理由を整理する。API費用の依頼上限は1米ドル。強制課金上限は未実装であり、全ファイルの精査や1ドル以内の課金を保証しない。未読・除外を確認済みと扱わない。詳細は同梱の共通ルールを参照。

## 対象の追加

新規タスク画面でファイル／フォルダーを選択するか、ドロップ領域へドラッグする。選択内容を確認し、追加ボタンで確定する。秘密情報、依存物、生成物などは除外するが、完全な秘密情報検出ではない。フォルダー選択はブラウザーによって動作が異なる。ネイティブFinderからのドラッグ受信は実機確認未完了。

GitHub入力は公開リポジトリから固定リビジョンのZIPを取得する。Web入力はURLと範囲を調査文へ登録するもので、その時点ではサイト診断しない。提供コードを自動実行する権限は与えない。

## 停止

不足条件が実際に作業を妨げる場合は `wait_for_user` で一度質問して停止する。回答待ちの引継ぎを繰り返さない。停止済みタスクは人が明示的に再開する。既存タスクへテンプレート更新は自動反映されない。

## 検証・制約

フォルダー取り込み・パス制限・回答待ち・無進展停止の対象テストとフロントエンドビルドを実施済み。ループ検知は完全ではなく、セキュリティー安全性の保証ではない。Cloudflareスキルの端末内インストール、API設定、データベース、認証情報はこのGit保存に含めない。
